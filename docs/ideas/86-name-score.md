# 定名：score

**状态**：在用（可改）

**一句话**：语言叫 score——一份谱：静态、可读、可以排练与演出；声部并行，休止是暂停，延长记号是等人。

**动机**：名字决定读的人第一眼把它归到哪一类。旧名 splice 命名的是「接合」，是动作；它没说出这门语言最要紧的三件事——计划是静态的、时间是显式的、执行可以被暂停与并行。语义是图、执行是 run 之后，名字该指「一份计划被演出」，这正是乐谱的位置：谱不发声，演出才发声；谱可以排练（试跑），可以从第 N 小节继续（恢复），可以有几个声部同时走（并行），可以有休止与延长记号（等待与请求）。

**形态**：

判定次序：意象 → 同域撞名 → 落盘 ASCII；意象优先于流畅，撞名优先于可打。

撞名结论（语言域加软件域。crates.io、PyPI、npm 与商标未逐个扫——定名前应补这一轮）：

- **score**：作为语言名未见占用；通用词，搜索噪声大（乐谱、评分、各种 score API 都叫这个）。
- **interlocking**：铁路联锁，意象精确——进路互斥、信号、机械上排不出冲突路径；但 11 个字母，且 Docker 早年有个编排插件叫 Interlock，正好撞在编排域。
- **escapement**：擒纵机构，把连续的力切成离散的步、每步必须释放；暂停是它的本职。太长，CLI 缩写会撞 escape。
- **detent**：定位珠，卡住直到被释放，就是「暂停与继续」本身；没人认识这个词。
- **rundown**：播出单，分段、有时长、中间有直播插入；语义准，但是新闻行话，且已有播出软件在用。
- **cue / loom / cadence / relay / tempo / jacquard**：分别撞 CUE 语言、Java 的 Project Loom、Cadence/Temporal、Relay、Grafana Tempo；jacquard 是人名，违反「不取人名」这条。

选 score：它一句话就能解释产品——一份谱，几个声部，按拍子演出。词汇也随之白送：staff、voice、cue、rest、fermata、tempo、rehearsal、performance。而这些不是比喻，就是运行模型：run = 演出，resume = 从第 N 小节继续，request = 延长记号，budget = 速度。

旧名 splice 保留在这一处作为改名记录；其余文档一律用 score。

落盘：目录与仓库 `score`，扩展名 `.score`，命令行 `score run x.score`。

**代价**：

- **通用词**：搜索与商标都难独占，必须先有域名与组织；否则「score」在搜索结果里等同于没有名字。
- **名词强、动词弱**：「score a run」不像话；上位命令要另挑措辞（`score run` / `score plan` / `score validate` 都还行）。
- **与「评分」的日常义冲突**：第一次听到会误解成打分工具，需要一句话解释。
