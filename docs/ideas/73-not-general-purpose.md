# 不是通用语言，是协调语言

**状态**：在用（可改）

**一句话**：splice 不计算，它接线——程序是一张图，计算发生在节点所指的外部操作里；语言负责的是顺序、数据流向、等待与审计。

**动机**：定位决定取舍。定成通用语言，就要有表达式、类型系统、标准库、优化器，并和 Rust / Go 比生态；定成协调语言，要守的线变成另外四条：可枚举、可定价、可恢复、可渲染。方法链与类型那一套（11–81 的大部分）曾经是语言本身，现在只剩边谓词会用到其中表达式与值的那一小块。

**形态**：

- **语义**：二进制图（[87](87-binary-graph-is-the-artifact.md)）——步骤、端口、边、子图、容器与 combine。
- **计算**：节点所指的外部操作——宿主函数、工具、request；语言自己不执行计算。
- **语言负责**：端口与类型（[83](83-subgraph-is-a-function.md)）、边与合并（[89](89-edges.md)、[88](88-containers-and-joins.md)）、seed 与 budget、validate、run 日志。
- **表示**：文本与渲染都是图的投影，不是第二份程序（[71](71-kdl-surface-syntax.md)、[87](87-binary-graph-is-the-artifact.md)）。

**代价**：

- **没有标准库就没有计算**：`x + 1` 要么是谓词里的一小段表达式，要么是一个节点；工具库的厚度就是可用性的下限。
- **生态薄**：每进一个新场景，都要配一套节点与工具。
- **不适合**：长计算、数值库、通用编程——那些交给节点后面的宿主语言。
- **规模假设仍小**：一张图几十到几百个节点是目标；上万节点不是。
